# SafeWalk — Frontend Subsystem (Member 3)

This directory contains the Streamlit web app, Folium mapping engine, and integration layer owned by **Member 3 (Frontend & Integration Lead)**.

## 📁 Files

* `app.py`: Main Streamlit application interface (Live Feed, Route Planning, SOS Generator, Voting UI).
* `map_builder.py`: Folium dark matter map builder with heatmap and route overlays.
* `requirements.txt`: Python package dependencies.

## 🚀 How to Run

1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
